# AoTech Solutions Website

The website is entirely inside `client`, as requested.

```text
AoTech-Solutions/
└── client/
    ├── public/
    ├── src/
    │   ├── pages/
    │   ├── components/
    │   ├── content/
    │   ├── config/
    │   ├── styles/
    │   └── types/
    ├── index.html
    ├── package.json
    └── README.md
```

Open [`client/README.md`](client/README.md) for commands and editing guidance. When deploying on Vercel, select `client` as the **Root Directory**.
